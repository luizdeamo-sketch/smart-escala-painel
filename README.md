# Smart Escala - painel público "Plantões em aberto"

Página estática de leitura. Mostra contagens agregadas de plantões em aberto (sem médico) de hoje e dos próximos 15 dias.
O acesso é pelo link com token (`?t=...`), gerado e revogado no Smart Escala. Não contém nome de médico, valores nem documentos.
O código-fonte fica no repositório privado do Smart Escala; aqui só o resultado compilado.
